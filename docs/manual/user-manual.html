Before you begin

About this manual

This manual explains how to install and use Alpha Premier Property Branding Studio (called “Branding Studio” in this manual). It is written for listing agents, marketing staff, and photographers who prepare property media for Alpha Premier Realty listings. No technical background is needed.

The chapters follow the order of a normal working session. If you only want to brand a batch of photos quickly, read Chapter 3, Quick start, which takes about five minutes.

Chapter 1

Introduction

Branding Studio applies the official Alpha Premier Realty frame (logo, gold accents, and contact numbers) to property photos and video clips. Every output has the same size and look, ready to post on listing sites and social media.

What you can do

  • Brand photos and videos in batches. Add many files at once and process them with one click.
  • Combine portrait photos. Two tall photos are placed side by side in one frame, so nothing is stretched or squashed.
  • Adjust framing before or after branding. Pan, zoom, rotate, fit, or fill each photo behind the frame.
  • Hide private details. Draw over house numbers, plates, family photos, or documents with the PEN tool.
  • Name files consistently. Output files are numbered automatically, for example Maple_Street_128_01.jpg.
  • Export in one step. Save everything as one ZIP file or as separate files in a folder.
  • Use other templates. Import extra frame images and switch between them.

How a session works

STEP 1SelectAdd photos and videos
STEP 2ArrangePair, separate, set the prefix
STEP 3CropFrame each photo, hide details
STEP 4ApplyAdd the branding frame
STEP 5ReviewPreview and fix
STEP 6ExportZIP or files

Before and after

Branding Studio converts each photo to a 1200 × 1000 pixel image and adds the frame on top. You do not need to resize your photos first.

Note: Your media stays on your computer

All processing happens on your PC. Branding Studio does not upload your photos or videos anywhere. The only internet connection it makes is to check for software updates (Chapter 13).

Chapter 2

Installation

System requirements

ItemRequirement
Operating systemWindows 10 (version 1809 or later) or Windows 11, 64-bit
Administrator rightsNot required. The app installs for your Windows user account only.
Extra softwareNone. Everything the app needs is included in the installer.
InternetOnly needed to download the installer and to check for updates.
DisplayWorks at 100%, 125%, 150%, 175%, and 200% Windows display scaling. Smallest window size: 840 × 480.

Option A: Install with the setup program (recommended)

  1. Download Alpha.Branding.Setup.exe from the official release page: github.com/Deign86/Alpha_Branding/releases/latest. Your IT team may also give you the file directly.
  2. Double-click Alpha.Branding.Setup.exe.
  3. Follow the on-screen steps. No administrator password is needed.
  4. When setup finishes, open Start and select Alpha Premier Property Branding Studio.

The app is installed to %LOCALAPPDATA%\Alpha Premier Realty\Branding Studio and a Start menu shortcut is created.

Option B: Run the portable version

  1. Download the Alpha.Branding-v2.4.0.zip file from the same release page.
  2. Right-click the ZIP file and select Extract All.
  3. Open the extracted folder and double-click Alpha.Branding.exe.

Use the portable version if you cannot install software on your PC, or to run the app from a USB drive.

Uninstalling

  1. Open Settings › Apps › Installed apps (Windows 11) or Settings › Apps & features (Windows 10).
  2. Find Alpha Premier Property Branding Studio, select ⋯ or the app name, then select Uninstall.

Uninstalling removes the app. Files you have already exported are not affected.

For IT administrators

The repository includes Install.ps1 for unattended deployment through tools such as Action1 RMM or Microsoft Intune. It supports -DownloadUrl, -AllUsers, -CreateDesktopShortcut, and -Uninstall. To turn off update checks on a PC, set the machine environment variable ALPHA_BRANDING_DISABLE_AUTO_UPDATE to 1. See the project README for full details.

Chapter 3

Quick start: brand your first batch

Follow these steps to brand a set of listing photos and save them as a ZIP file. It takes about five minutes.

  1. Open Branding Studio from the Start menu.
  2. Select SELECT MEDIA (or press Ctrl + O). Choose your photos and select Open. You can also drag files from File Explorer onto the window.
  3. In FILENAME PREFIX, type a name for this listing, for example Maple_Street_128. The Preview box shows the first file name.
  4. Check that BRANDING TEMPLATE shows Alpha Premier Classic.
  5. Optional: select EDIT CROP on any photo to change its framing (Chapter 7).
  6. Select APPLY BRANDING (or press F5). Wait until the status reads Completed.
  7. Look over the results. Select PREVIEW on a result to see it full size.
  8. Select EXPORT › Export as ZIP Archive (.zip), choose where to save, and select Save.
Tip

By default, portrait (tall) photos are combined in pairs. Four photos with two portraits give three results: two single photos and one side-by-side pair. See Chapter 6 to change this.

Chapter 5

Adding and managing media

Supported file types

TypeFile extensionsOutput
Photos.jpg .jpeg .jfif .png .bmp .webp .heic .heifJPG, 1200 × 1000 pixels
Videos.mp4 .mov .wmv .avi .m4v .mkv .webmMP4, 1200 × 1000 pixels

Files of other types are ignored. HEIC and HEIF photos (common on iPhones) are converted automatically.

Add media

Use any of these methods:

  • Select SELECT MEDIA or press Ctrl + O. Hold Ctrl to choose several files. This starts a new selection; if your staged photos have crops, PEN marks, pairs, or SOLO settings, the app asks before replacing them.
  • Drag files from File Explorer and drop them on the window. A message reads DROP VIDEOS & PHOTOS HERE TO IMPORT. Dropping onto photos you have already staged adds the new files; it does not replace them.
  • Select ADD MORE to add files to the photos you already have. Files that are already staged are not added twice.

The staged media area

After you add files, each one appears as a card. The bar above the cards contains actions for the whole batch.

Chapter 6

Photo layouts and pairing

The branding frame is wider than it is tall (6:5). Landscape photos fill it well. A single portrait photo would leave large empty sides, so Branding Studio can place two portrait photos side by side instead.

Choose a layout for the whole batch

ButtonResultBest for
COMBINE IMAGES (default)Portrait photos are paired in the order you added them. Landscape photos stay single.Mixed batches with tall room shots
KEEP SEPARATEEvery photo is branded on its own, including portraits. Manual pairs and SOLO settings are ignored.When every photo must appear alone

The active layout button is shown in gold.

How automatic pairing decides

  1. Photos you paired by hand are always kept together.
  2. The remaining portrait photos are paired in order: first with second, third with fourth, and so on.
  3. If one portrait is left over, it is paired with the last landscape photo in the batch.
  4. If there is no landscape photo to use, the leftover portrait is placed on both halves of the frame.
  5. Results stay in the same order as your original files.

Set a single photo to SOLO

To keep one photo out of pairing while other photos still combine, select SOLO on its card. The button turns gold. Select it again to turn SOLO off.

Pair two specific photos

If automatic pairing puts the wrong photos together, pair them yourself. Use either method:

  • Drag and drop: drag one photo card onto another photo card. A highlighted border shows where it will drop.
  • PAIR button: select PAIR on a card. It is paired with the next photo in the list that is not SOLO, not a video, and not already paired.

Paired cards show UNPAIR and a Paired with line naming the partner. Select UNPAIR to remove the pair. Manual pairs are kept when you apply branding and when you rebrand a result.

Tip

In a pair, the photo that comes first in the staged list appears on the left half of the frame.

Note

SOLO photos and videos cannot be paired, so PAIR is faded on them. Turn SOLO off first.

Chapter 7

The Crop & Alignment Editor

The editor lets you choose exactly which part of a photo shows inside the frame. The branding overlay is shown on top, so what you see is what will be exported.

To open it, select EDIT CROP on a staged photo, on a branded result, or in the Preview window.

#ControlWhat it does
1Output sizeThe final size of this image: 1200 × 1000 px, or 600 × 1000 px for each half of a pair.
2CanvasDrag the photo to move it, or click it and use the arrow keys. Scroll the mouse wheel to zoom. Faint guide lines divide the frame into thirds.
3PANNormal mode (gold when active). Dragging moves the photo.
4PENDrawing mode for hiding details. See the next section.
5SIZEPen size for PEN mode.
6UNDO / CLEAR MARKSRemove the last pen mark, or all pen marks on this photo.
7ZOOM− and + change zoom by 10%; the slider covers 20% to 400%. The box shows the current level.
8FIT TO FRAME / FILL FRAMEFit shows the whole photo with no cropping. Fill covers the whole frame and crops the edges evenly.
9ROTATE 90°Turns the photo a quarter turn clockwise. Use it for sideways photos.
10RESET CROPReturns pan, zoom, and rotation to the default. PEN marks are kept.
11OFFSETHow far the photo has been moved, in pixels, with a hint for the current mode.
12CANCEL / SAVE CHANGESCancel (Esc) closes without changes. Save (Enter) keeps your changes.

Frame a photo

  1. Select EDIT CROP on the photo.
  2. If the photo is sideways, select ROTATE 90° until it is upright.
  3. Select FILL FRAME for a clean, edge-to-edge image, or FIT TO FRAME to keep the whole photo.
  4. Scroll or use the zoom slider to adjust the size, then drag the photo to position it. For fine moves, click the photo and press the arrow keys (hold Shift for bigger steps).
  5. Keep important parts away from the logo and the contact-number strip at the bottom.
  6. Select SAVE CHANGES. The card now shows a CROPPED badge.

Edit a combined pair

When you edit a combined result, the editor shows LEFT PHOTO and RIGHT PHOTO at the top. Select one to adjust it. Each half has its own zoom, position, rotation, and PEN marks.

Hiding details with the PEN tool

Use PEN to paint solid marks over things that should not appear in a public listing, such as house numbers, car plates, family photos, mail, or documents. The marks are permanent in the exported image.

  1. In the editor, select PEN. The button turns gold.
  2. Drag the SIZE slider. Left is a fine line; right is a thick pen.
  3. Click and drag over the area to hide. Draw several strokes until it is fully covered.
  4. To remove the last stroke, select UNDO or press Ctrl + Z. To remove all marks on this photo, select CLEAR MARKS; UNDO brings them back if you change your mind.
  5. Select PAN (or press Esc) to go back to moving the photo.
  6. Select SAVE CHANGES.
Note

PEN marks stay attached to the photo. They move, zoom, and rotate with it, and they are kept when you rebrand a result or reset its crop. In a pair, marks belong to the half that was selected when you drew them.

Caution

Only UNDO and CLEAR MARKS remove PEN marks; RESET and RESET ALL CROPS keep them. Removing a photo from the selection, or CLEAR ALL, discards its marks. Check sensitive photos again before you export.

Tip

In PEN mode, the first press of Esc returns to PAN mode. A second press of Esc closes the editor without saving.

Chapter 8

File names and branding templates

Filename prefix

Every output file is named with the prefix, an underscore, and a number. The default prefix is AlphaPremier_Photo.

Prefix you typeFiles created
Maple_Street_128Maple_Street_128_01.jpg, Maple_Street_128_02.jpg, Maple_Street_128_03.mp4 …
(left empty)AlphaPremier_Photo_01.jpg, AlphaPremier_Photo_02.jpg …
  • Numbers have two digits (01, 02 …). Batches of 100 or more items use three digits (001, 002 …).
  • Characters that Windows does not allow in file names (/ \ : * ? " < > |) are removed automatically.
  • Photos are saved as .jpg and videos as .mp4.
  • The ZIP export is named <prefix>_Export.zip by default.
Tip

Use the property address or listing ID as the prefix. Files from different listings will then never be mixed up.

Branding templates

A template is the frame image placed over each photo. Alpha Premier Classic is built in and marked OFFICIAL. It cannot be deleted.

Import a template

  1. Select + IMPORT next to BRANDING TEMPLATE.
  2. Choose a PNG, JPG, JFIF, or WEBP image and select Open. Use a PNG with a transparent center so the photo shows through.
  3. The app checks the file. If it is valid, the template is saved and selected. If not, a message explains the problem.

The badge beside the label shows the template’s shape, for example 6:5 (1.20:1) · Official Ratio. The shape of the template is always kept; it is never stretched.

Switch or delete a template

  • Choose a template from the BRANDING TEMPLATE list. It is used the next time you apply branding or edit a crop.
  • To delete a custom template, select it, select DELETE, then confirm with Yes.
Note

Imported templates are stored on your PC in %LOCALAPPDATA%\Alpha Premier Realty\Branding Studio\Templates and are available every time you open the app.

Chapter 9

Applying branding

  1. Check the staged items, layout, prefix, and template.
  2. Select APPLY BRANDING, or press Ctrl + B or F5.
  3. Watch the STATUS line and progress bar. Videos take longer than photos.
  4. When the status reads Completed, the workspace switches to BRANDED ASSETS.

What happens to each item

ItemResult
Landscape photoCropped to fill the 1200 × 1000 frame (or framed as you set in the editor), then branded.
Portrait pairEach photo fills one 600 × 1000 half, then the frame is added.
SOLO photoBranded on its own in the full frame.
VideoThe whole video is fitted and centered in a 1200 × 1000 MP4, and the frame is shown for the full length. Videos are not cropped.
Note

If one file cannot be processed (for example, it is damaged), the status names that file and the rest of the batch continues.

Caution

Selecting APPLY BRANDING again starts a new session and replaces the current results. The app always asks you first, so you can export them (Chapter 12).

Preview window

  • Press ← and → or select ◀ PREVIOUS and NEXT ▶ to move between results.
  • For videos, use the play/pause button, the timeline, and the mute button. Press Space to play or pause.

Fix a result without starting over

  1. Select EDIT CROP on the result card or in the Preview window.
  2. Adjust the framing or add PEN marks, then select SAVE CHANGES.
  3. Only that result is rebranded. Its name and position in the batch do not change.
Chapter 11

Saving and exporting

Branded results exist only inside the app until you save or export them. Choose the method that suits how you will share the files.

MethodHowResult
Export as ZIP Archive (.zip)EXPORT › Export as ZIP Archive (.zip), or Ctrl + E (also Ctrl + S)One ZIP file with every result
Export as Individual Files…EXPORT › Export as Individual Files…, or Ctrl + Shift + EEvery result saved into a folder you choose
Save one resultSAVE on a result cardOne JPG or MP4 file

Export everything as a ZIP file

  1. Select EXPORT. A menu opens below the button.
  2. Select Export as ZIP Archive (.zip).
  3. Choose a folder. The file name is filled in as <prefix>_Export.zip; you can change it.
  4. Select Save. The status shows progress and then confirms the export.

Export as separate files

  1. Select EXPORT › Export as Individual Files…
  2. Choose or create a folder and confirm.
  3. Each result is saved with its numbered name, for example Maple_Street_128_01.jpg.
Caution

Files in the folder with the same names are replaced without asking. Use an empty folder for each listing.

Tip

ZIP files are easiest to email or upload in one step. Separate files are easiest to drag into a listing website.

Chapter 12

Sessions and unsaved work

A session is one batch of branded results. Branding Studio protects your results so you do not lose them by accident.

The app asks before it replaces or closes a session that has results, when you:

  • apply branding again while you still have results,
  • load a new batch of media,
  • select CLEAR ALL in the branded assets view, or
  • close the app.
#ChoiceWhat happens
1CANCELNothing changes. You return to your current session.
2DISCARD EDITS & CONTINUEThe current results are discarded and the app continues.
3SAVE & CONTINUEYou save the current results as a ZIP file first, then the app continues.
Caution

Discarded results cannot be recovered. Your original photos and videos are never changed or deleted, so you can brand them again.

  • every 8 hours while it is running, and
  • when you select CHECK FOR UPDATES.

When a newer version is available, this window appears:

Frequently asked questions

Are my original photos changed?

No. Branding Studio only reads your originals. Branded copies are saved only where you export them.

Does the app need the internet?

Only to check for and download updates. Branding, cropping, and exporting work offline.

Can I close the app and continue later?

No. Results are not kept after the app closes. Export your results before closing; the app reminds you if you forget.

Why did four photos give me three results?

Two portrait photos were combined into one frame. Select KEEP SEPARATE if you want one result per photo.

Can I remove PEN marks after exporting?

Not from the exported file. While the session is still open, select EDIT CROP on the result, select CLEAR MARKS, save, and export again.

Where do I get help?

Contact your office IT administrator. Releases and release notes are listed at github.com/Deign86/Alpha_Branding/releases.
